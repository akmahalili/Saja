# Pintar Sifir

Apps sifir 1–10 dwibahasa (BM / EN) untuk murid sekolah rendah. Murid boleh bermain dengan **sentuhan**, **isyarat tangan** (kamera) atau **arahan suara** (mikrofon).
Bilingual (Malay / English) times-tables app for primary pupils: play by **touch**, **hand gestures** (camera) or **voice commands** (microphone).

Pautan / Link: https://akmahalili.github.io/Saja/

- Android: Chrome → menu ⋮ → Pasang apps / Install app
- iPhone & iPad: Safari → Kongsi / Share → Tambah ke Skrin Utama / Add to Home Screen
- Windows: Chrome atau Edge → ikon Pasang di bar alamat / Install icon in the address bar
- Mac: Chrome → ikon Pasang / Install icon; Safari → Fail / File → Tambah ke Dock / Add to Dock

Pengesan tangan menggunakan MediaPipe Hand Landmarker (Apache 2.0), disertakan dalam folder `mediapipe/`.
